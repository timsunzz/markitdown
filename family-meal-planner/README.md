# 全家营养餐 · 微信小程序

帮职业家庭主妇/主夫搞定"今天吃什么"的微信小程序：

- 🗓 **每日菜单自动生成**：早/午/晚三餐，荤素汤主食科学搭配，每天自动换新，不满意可"换一换"
- 👨‍👩‍👧 **按家庭人口定制**：设置家里的成人、老人、孩子（含年龄），份量与营养目标自动换算
- 🥗 **营养学考量**：依据《中国居民膳食营养素参考摄入量（2023 版）》计算全家能量、蛋白质、钙、铁目标，菜单页实时显示达成度；家有 10 岁以下孩子自动避开辛辣菜
- 📖 **每道菜完整做法**：食材（按全家人口自动换算克数）、分步做法、营养成分、营养师小贴士
- 🛒 **一键购买**：一天菜单一键聚合成购物清单（按蔬果/肉蛋/水产/奶豆/粮油分类），一键复制后跳转**奥乐齐微信小程序**或**盒马 App** 粘贴下单买齐

纯前端实现（无需服务器/云开发），菜谱数据内置，审核友好、维护成本为零。

## 目录结构

```
family-meal-planner/
├── app.js / app.json / app.wxss     # 全局配置与样式
├── project.config.json              # 微信开发者工具项目配置
├── data/recipes.js                  # 菜谱数据库（28 道菜，可自行扩充）
├── utils/
│   ├── nutrition.js                 # 营养目标计算（按成员角色/年龄）
│   ├── planner.js                   # 每日菜单生成引擎（按日期确定性生成）
│   └── shopping.js                  # 购物清单聚合与文本生成
└── pages/
    ├── index/                       # 今日菜单 + 营养分析
    ├── family/                      # 家庭成员管理
    ├── recipe/                      # 菜谱详情
    └── shopping/                    # 购物清单 + 一键购买
```

## 本地运行（5 分钟）

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开工具 → 导入项目 → 选择 `family-meal-planner` 目录
3. AppID 先选"测试号"即可预览、真机调试

## 上架流程（让所有人都能用）

1. **注册小程序账号**：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册。个人主体即可上架本程序（无支付、无社交功能）；如后续想接广告或企业运营，选企业主体。
2. **完成小程序备案**：2023 年 9 月起新小程序须完成 ICP 备案才能上架，在小程序后台按指引提交（个人主体需要身份证 + 人脸核验，通常 1-2 周）。
3. **填写基本信息**：名称（如"全家营养餐"）、头像、简介；**服务类目**选择「生活服务 > 菜谱」（个人主体可选，无需额外资质）。
4. **填入 AppID**：把后台的 AppID 填到 `project.config.json` 的 `appid` 字段。
5. **配置一键跳转奥乐齐（可选）**：
   - 微信里打开「奥乐齐ALDI」官方小程序 → 右上角"…" → 更多资料，查到其 AppID
   - 填入 `pages/shopping/shopping.js` 顶部的 `ALDI_APPID`
   - 未配置时也不影响：按钮会复制清单并引导用户搜索该小程序粘贴下单
   - 盒马无微信小程序（阿里生态），采用"复制清单 → 盒马 App 粘贴搜索"方式
6. **上传代码**：开发者工具 → 上传 → 后台「版本管理」提交审核。审核要点：本程序无采集用户信息、无支付、无 UGC，页面内已带"营养建议仅供参考"声明，一般 1-3 天可过。
7. **发布**：审核通过后点击发布，所有微信用户即可搜索使用。

## 常见二次开发

- **加菜谱**：在 `data/recipes.js` 按现有格式追加即可，注意"1 份 = 1 个标准成人份"的份量约定
- **周菜单/收藏/云端同步**：可接入微信云开发（`wx.cloud`），当前版本刻意保持零后端以便快速过审
- **真正的 API 下单**：盒马/奥乐齐均未开放第三方下单 API，需商务合作（BD）后替换 `shopping.js` 中的跳转逻辑
