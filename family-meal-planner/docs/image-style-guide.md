# 菜品配图风格指南与 AI 生图提示词

## 视觉定位

目标用户：预算有限、但渴望把日子过精致的女性。配图要传达的不是餐厅大片，而是**"我在家也能做出这样的一餐"**的治愈感与可实现感。

**风格关键词**：自然暖光（窗边侧光）· 浅原木/亚麻质感背景 · 白瓷或粗陶家用餐具 · 45° 半俯拍 · 浅景深 · 热气感 · 色系不超过 3 种 · 家常份量（不过度摆盘）

**重要经验**：提示词必须以**成品外观描述**开头，不能只给菜名——生图模型不认识"公瑾爆蛋""地三鲜"这类名字，只给名字会生成完全错误的图。下方每条提示词都已内置外观描述。

## 使用方法

1. 即梦 AI / 豆包选"写实/摄影"风格，比例 4:3；复制对应提示词生成，同批生成保证风格统一
2. 挑好的图压缩到 200KB 以内，上传微信云开发存储或自有图床
3. 图片链接填入 data/recipes.js 对应菜谱的 image 字段即自动替换

> AI 生成图商用请确认平台授权条款；请勿直接使用小红书等平台他人照片。
