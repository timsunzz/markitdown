# 菜品配图风格指南与 AI 生图提示词

## 视觉定位

目标用户：预算有限、但渴望把日子过精致的女性。配图要传达的不是餐厅大片，而是**"我在家也能做出这样的一餐"**的治愈感与可实现感。

**风格关键词**：自然暖光（窗边侧光）· 浅原木/亚麻质感背景 · 白瓷或粗陶家用餐具 · 45° 半俯拍 · 浅景深 · 热气感 · 色系不超过 3 种 · 家常份量（不过度摆盘）

**避免**：高级餐厅摆盘、深色大理石背景、过饱和滤镜、俯视全家福大长桌（距离感太强）。

## 使用方法

1. 打开即梦 AI / 豆包（免费额度足够）或 Midjourney，选"写实/摄影"风格，比例 4:3 或 1:1
2. 复制下方对应菜品的提示词生成，同一批尽量一次性生成保证风格统一
3. 挑好的图统一压缩到 200KB 以内，上传微信云开发存储（或自有图床）
4. 把图片链接填入 data/recipes.js 对应菜谱的 image 字段，列表缩略图与详情大图自动替换

> 注意：AI 生成图商用请确认所用平台的授权条款；请勿直接使用小红书等平台他人照片。
